# 第 5 周：API、网页、轨迹与评估

- 核心：逐个调用 health、documents、research、approve、cancel 和 report；为状态错误补 API 测试。
- 必须提交：OpenAPI 截图或接口表。

## Day 22：后台任务和 SSE

- 核心：跟踪 `_run_task()`、EventBroker 和浏览器 EventSource；测试断开与取消。

## Day 23：简单网页

- 核心：完成上传、创建、确认、进度、取消和报告完整操作；改善错误展示。

- 口头检查：前端展示的状态以谁为准？

## Day 24：可观测性和成本
