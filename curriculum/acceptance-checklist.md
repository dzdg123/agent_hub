# 结业验收清单

## 功能

- [ ] 网页可以创建、确认、观察和取消任务。
- [ ] TXT、Markdown、文本型 PDF 可以上传并索引。
- [ ] 网页和本地文档可以同时参与研究。
- [ ] MCP Server 可以列出并调用四个只读工具。
- [ ] 报告包含可解析到真实来源的引用。

## 可靠性与安全

- [ ] 模型、网页、MCP 失败不会造成无限循环或进程崩溃。
- [ ] 所有外部调用有超时，重试次数有限。
- [ ] 取消后不产生新的模型或工具调用。
- [ ] MCP 文件工具无法越过 DOCUMENT_ROOT。
- [ ] 抓取器拒绝本机、私网和保留地址。
- [ ] 密钥不在源码、数据库、报告和日志中。

## 评估与交付

- [ ] 20 条任务至少 17 条完整执行。
- [ ] 本地问题 Top-3 检索命中率达到 80%。
- [ ] 所有引用 ID 有真实 Source。
- [ ] 抽查事实的引用支持率达到 80%。
- [ ] 全部核心自动测试通过。
- [ ] README 能指导新用户从安装走到首份报告。
- [ ] 有架构图、示例报告、基线与最终评估。
